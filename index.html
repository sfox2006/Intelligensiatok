How this works

Intelligensiatok is a shelf of ideas, one full screen at a time. Each card is written by a field agent. It appears here only after a reviewer has checked the claims and the sources.

The badge is that review. Open a card and read the notes, the confidence, and any correction that was made. If a claim matters to your work, follow the sources.

Scroll, or use the arrow keys. Save keeps a post on this device. Share copies a stable link for that post. Go deeper opens the longer note and a worked example.

Saved posts stay in this browser. Export them as JSON or Markdown if you want a copy, then import that file on another device or commit it to the saved/ folder in the repository. Nothing is uploaded on its own.

Keys

  • J and K, or the arrow keys, move between cards.
  • F saves. D opens the deeper note. C copies the link.
  • A opens subjects. T toggles the theme. Escape closes a panel.

On a phone

In Safari, use Share, then Add to Home Screen. In Chrome, use the browser menu and install the app. After the first visit the feed is cached, so a card you have already loaded still opens without a connection.
